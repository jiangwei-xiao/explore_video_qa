# Wavelet-based Frame Selection by Detecting Semantic Boundary for Long Video Understanding

## 研究场景

论文研究长视频问答中的训练免费关键帧选择。输入是长视频和用户问题，方法先计算随时间变化的问题相关性信号，再按语义变化划分连续片段、分配有限帧预算，并在片段内部选帧，最终将固定数量的画面交给现有LVLM。

实验覆盖Video-MME、MLVU和LongVideoBench，视频平均长度约11–17分钟；不使用字幕。方法接入LLaVA-OneVision、LLaVA-Video、Qwen2.5-VL和InternVL3等不同模型，测试8／16／32／64个最终输入帧。

在五篇论文中，WFS-SB与我们的“先形成片段、再在片段内MMR”最接近。二者的主要区别是：我们使用固定20秒重叠滑窗并只选择四段，WFS-SB根据相关性信号的多尺度变化生成可变长度语义片段，并自适应分配预算。

## 要解决的问题

作者认为Top-K问题相关性把视频当作无结构的帧集合，容易输出时间上零散、内容重复的高分帧，不能保留叙事过程。直接在原始相关性曲线上检测峰值或梯度也不可靠：评分模型噪声、短暂视觉扰动、光照和镜头运动都会制造高频波动。

相关性信号还同时包含不同时间尺度：挥手可能只持续数秒，完整烹饪过程可能持续数分钟。论文要从噪声较强、非平稳、多尺度的时间信号中识别更稳定的语义边界，然后根据每段的信息量分配有限预算，最后避免片段内重复画面。

## 核心方法论与原理解析

WFS-SB先按1 FPS抽取候选帧，用BLIP-2的ITM头计算每帧与问题的匹配分数。整条分数序列被视作“时间相关性信号”，而不是彼此独立的Top-K分数。

第一阶段是**小波语义边界检测**。论文使用Daubechies-4离散小波变换，将相关性信号递归分解为低频近似项和不同尺度的高频细节项。分解层数随候选序列长度N调整：`J=max(1, floor(log2 N)−l)`。仅保留最粗尺度的细节系数进行逆变换，得到抑制短时噪声、突出较大语义变化的信号；其绝对值峰值作为边界，将整段视频划分为连续、可变长度的语义片段。

第二阶段是**片段过滤与自适应预算分配**。每段重要性由四项加权组成：片段时长占比、平均相关性、最高相关性、段内分数方差相对全局方差。默认权重为0.4／0.2／0.3／0.1。低于 `mean(importance)−η×std(importance)` 的片段被过滤；其余片段经Softmax按重要性分配总预算，取整余数按小数部分补齐。

第三阶段是**片段内局部MMR**。每段先选择相关性最高的一帧作为锚点，然后按

`λ × 问题相关性 − (1−λ) × 与本段已选帧的最大相似度`

逐步补齐该段预算，默认 `λ=0.5`。不同片段独立执行MMR，避免一个片段的视觉外观压制另一个片段的相似但可能有用画面。

与我们当前方法相比，WFS-SB已经覆盖“分段—片段预算—局部MMR”完整框架。它没有固定片段数、固定长度和均分预算；所有时间区域先参与连续语义分段，再按重要性过滤。我们的高分重叠窗方法更像从全片直接截取四个候选区域，遗漏后没有全局回补。

## 实验配置

- 候选默认按1 FPS抽取；附录还按视频长短测试1／0.75／0.5／0.25 FPS组合。
- 默认用BLIP-2-ITM-ViT-g计算问题与帧匹配；同时测试BLIP-ITM、CLIP-ViT-B和SigLIP。
- 小波为db4，漂移参数 `l=3`；边界从最粗尺度重建信号的峰值获得。
- 片段重要性权重为时长0.4、平均分0.2、最高分0.3、方差0.1；过滤参数 `η=1.2`。
- 片段内MMR权重 `λ=0.5`。
- 数据集为Video-MME 2700题、MLVU 2174题、LongVideoBench验证集1337题；不使用字幕。
- 下游模型包括LLaVA-OneVision-7B、LLaVA-Video-7B、Qwen2.5-VL-7B和InternVL3-8B；预算K为8／16／32／64帧。
- 使用LMMs-Eval报告准确率，主要实验在NVIDIA A800 80GB上完成。

## 实验设置与效果（如果与其他方法做了对比也要简述其他方法是如何做的）

主要公平比较将WFS-SB接入同一模型，并与对应均匀采样成绩比较：

| 模型与帧数 | Video-MME：基线→WFS-SB | MLVU：基线→WFS-SB | LongVideoBench：基线→WFS-SB |
|---|---:|---:|---:|
| LLaVA-OneVision-7B，8帧 | 54.1→59.3 | 58.6→67.2 | 54.2→59.8 |
| LLaVA-Video-7B，8帧 | 56.2→61.7 | 57.4→66.9 | 54.9→61.1 |
| Qwen2.5-VL-7B，32帧 | 61.2→64.4 | 59.7→70.4 | 58.9→64.4 |
| InternVL3-8B，32帧 | 65.6→67.4 | 68.4→74.8 | 58.5→62.9 |

论文比较的Frame-Voyager和FrameOracle是训练型选择器；BOLT按问题相关性进行概率抽帧；AKS在相关性集中和时间覆盖之间递归决策；MDP³通过查询条件DPP和动态规划建模列表多样性与顺序；A.I.R.使用强VLM迭代验证并在局部补采样。作者对有公开代码的方法重新评测，对其他方法引用可比设置下的报告结果。WFS-SB在表中多数模型和数据集组合上达到最高或次高增益，但不同方法的基础模型、帧数与报告来源并非全部完全一致，阅读绝对排名时仍应看每组的Base→Method增量。

组件消融使用Qwen2.5-VL-7B、16帧：

| 配置 | Video-MME | MLVU |
|---|---:|---:|
| 均匀采样 | 57.7 | 56.2 |
| 完整WFS-SB | **61.9** | **67.9** |
| 不用DWT，直接取原始局部极小值 | 60.8 | 64.6 |
| 不用DWT，使用原始梯度 | 61.2 | 66.8 |
| 平均分配片段预算 | 61.6 | 67.4 |
| 不用MMR，片段内Top-K | 60.9 | 66.7 |
| 不用MMR，片段内均匀 | 59.2 | 62.7 |

消融说明小波边界是主要差异来源之一；自适应预算的净增益相对较小，但片段内MMR比Top-K和均匀选择都更好。不同评分器在Qwen2.5-VL、16帧下均优于均匀采样：CLIP-ViT-B达到Video-MME 61.7、MLVU 66.5、LongVideoBench 60.6；默认BLIP-2-ITM为61.9／67.9／62.5。由此可见CLIP可以承载该框架，论文贡献主要来自时间信号建模和层次化组织。

效率表以Video-MME平均1040个候选帧、最终32帧为例：BLIP-2 ITM信号提取约19.4秒，DWT与边界检测近似0秒，预算分配近似0秒，MMR约0.7秒，下游推理约4.4秒。瓶颈是全片相关性计算，不是小波或MMR本身。

附录进一步使用按时长降低FPS的策略：短／中／长视频分别使用1／0.5／0.25 FPS时，ITM时间由19.4秒降至5.8秒；8／16／32帧准确率为59.4／61.9／64.6，默认1 FPS为59.3／61.9／64.4。论文据此认为长视频可以降低候选密度，但该策略仍先确定FPS后全局计算相关性，并没有局部重新加密。

对我们的直接影响是：固定滑窗和均分预算很难作为WFS-SB之后的充分创新。若继续层次化路线，需要证明一个不同且必要的原理，例如更可靠的证据充分性判断、对短暂局部状态的可恢复搜索，或在不计算全片密集相关性的条件下仍能保持有效片段。
