## 研究场景

面向长视频问答，输入完整视频、问题及任务提供的答案选项，在固定最终帧预算下选择有效画面，交给冻结的视频视觉语言模型回答，同时考虑两类证据需求：

- **局部细节**：集中查看少数相关区域，保留清晰视角和关键状态。
- **全局覆盖**：覆盖多个相关事件，保留跨片段的信息。

混合或无法明确判断的问题采用折中策略。默认使用LLaVA-Video-7B、1 FPS初始候选、BLIP评分、最终16帧。目标是提高同预算问答效果；额外补查成本单独记录。

## 要解决的问题

均匀采样可能遗漏重点位置，Top-K可能集中于重复画面。核心假设是：

> 根据问题的证据范围，逐步分配片段覆盖与局部细节预算，再通过有限补查改善画面选择，能否提高同预算问答效果？

片段划分和MMR借用已有思想；拟研究的主要差异是**问题范围引导的预算竞争及其与条件补查的配合**。当前不预先宣称创新或有效性，也不将相似度、覆盖值直接解释为证据充分性。

## 核心方法论与原理解析

整体流程：`问题范围判断＋1 FPS全片扫描 → BLIP评分与候选分段 → 逐帧竞争16个名额 → 条件局部补查 → 固定配额段内重选 → 按时间排序 → VLM回答`。

### 1．问题范围判断

复用已加载的LLaVA，对原问题额外进行一次仅文本分类，不输入视频、答案或标准题型标签。固定分类提示词和贪心生成：

| 输出 | 含义 | 覆盖权重λ |
|---|---|---:|
| LOCAL | 主要需要某个局部目标或事件的细节 | 0.2 |
| GLOBAL | 需要跨多个事件收集或汇总信息 | 0.8 |
| MIXED | 同时需要定位与关系上下文，或无法确定 | 0.5 |

无法解析时使用MIXED并记录，不重复询问。标签只影响分配倾向，不排除任何片段；额外调用计入成本，不把标签或模型自评分当作可信概率。

### 2．建立候选片段

- 按1 FPS抽取候选，固定0.25秒采样相位，保存真实源帧位置和时间戳。
- 使用 `Salesforce/blip-itm-base-coco`，以原问题计算ITM匹配分数；第一版不加入选项聚合，标准答案不进入选择器。
- 使用BLIP视觉编码器的图像CLS特征，归一化后计算帧间余弦相似度，不使用图文交互后的文本特征。
- 借用WFS-SB独立分段器：db4小波、对称边界处理、分解漂移参数3、峰值高度系数0.5、突出度系数0.05、最小峰距 `max(5, floor(0.02N))`，其中N为初始候选数。只借用分段，不继承其片段过滤和预算分配。
- 全部有效片段参与竞争，无有效边界时将全片作为一个片段。边界与片段代表分数在初始扫描后固定；候选片段不等同于已确认的真实事件。

分段依据为WFS-SB的[官方核心代码](https://github.com/MAC-AutoML/WFS-SB/blob/main/wfs/core.py)与[官方配置](https://github.com/MAC-AutoML/WFS-SB/blob/main/configs/wfs_defaults.yaml)，实施时记录代码版本。

### 3．逐帧竞争预算

对尚未选择的帧i计算：

$$
G(i)=(1-\lambda)r_i+\lambda\frac{R_e}{1+n_e}-0.2D_i
$$

| 量 | 定义 |
|---|---|
| rᵢ | BLIP的0–1 ITM匹配分数，不重新进行全片最小—最大拉伸 |
| Rₑ | 所属片段在初始候选中的最高相关性 |
| nₑ | 所属片段已经选中的帧数 |
| Dᵢ | 与本片段已选帧的最大视觉相似度，截断到0–1；本段尚未选帧时为0 |

每段提出当前最高分候选，全局选出其中最高的一帧，更新该段状态，重复至16帧。同分按源时间、候选编号排序。覆盖奖励随本段已选帧数递减，允许片段获得零帧或多帧，不固定片段数量、不均分配额。所有分数均为选择代理指标，不解释为答对概率。

### 4．条件局部补查

粗选结束后，每个已获得配额的片段，取其已选帧中相关性最高者作为热点候选：

1. 热点相关性达到全片初始候选的第75百分位。
2. 在热点前后2秒内，用初始候选计算局部未覆盖程度：每帧相关性乘以其与该范围内已选帧的差异程度，再取平均。差异程度为1减去与这些已选帧的最大视觉相似度，相似度截断到0–1。
3. 未覆盖程度不大于10⁻⁶时跳过；其余按“热点相关性×局部未覆盖程度”降序排列，同分按时间排序。
4. 最多选择两个补查范围不重叠的热点；与已选范围重叠的热点跳过。

每处前后各2秒，补到4 FPS，采用与初始网格对齐的新增时间点并排除已有候选。每处最多12个新增候选，每题最多24个；仅补查一次，视频首尾裁剪到有效范围，按真实源帧去重，不补重复帧。

### 5．固定配额，段内重选

新增帧按真实时间归属初始片段。对已有配额且获得新候选的片段，在新旧候选并集中，使用与粗选一致的相关性和局部重复惩罚重新选满原配额。

片段边界、Rₑ及各段配额保持不变；零配额片段不因补查获得新名额。新帧没有优先权，最终仍为16个不同帧，按源时间排序输入VLM。

本版补查改善已关注区域的画面，不能保证挽救完全遗漏的片段；按代理准则重选也不保证真实答题效果提高。

## 2026-09-17｜近期优化探索计划

### 目标与判断尺度

近期按“定位—局部取证—证据保留”主线分环节验证。目标是缓解有限帧预算下的漏采、漏选和无效占位，提高总体正确率，或对某一类问题形成可重复的改善；不要求一个方法解决所有题型。代表题改善可以支持继续探索，代理指标改善不能直接称为正确率提升，其他题仍有问题也不自动否定方法方向。

对上文R判断作范围澄清：未取得收益的是这一套具体配置，不是对局部补查方向作终局否决。136张补入帧中109张距区域边界≤0.3秒，最远0.52秒；103-1补到动作过渡，022-2补入直接文字信息，同时存在黑屏/转场与错误位置补查。这些支持研究定位、覆盖和补位细节，不证明改变参数必然有效。R代码保留为可复算的实验对照，不成为默认方法；旧运行、报告副本和快照不改写。

### 整体框架与依赖

`粗候选扫描 → 多位置锚点提议 → 利用上下文确认定位 → 有限局部取证 → 按证据贡献选择单帧/小帧组 → 冻结模型问答`。

初始候选可直接进入最终输入，不强制补查。预算约束贯穿全流程，不固定每个锚点相同配额。

- **定位价值不等于回答价值**：垃圾桶可以是取证入口，但物体身份与投掷关系可能由其他帧提供。定位分数不应自动成为最终保留优先级的唯一依据。
- **锚点先于补查**：初期保留原问题BLIP作为低成本位置提议，不把高ITM分数等同于已确认的定位价值。锚点数量与最终16帧解耦；整理相邻位置只影响搜索入口，不宣称语义事件分段，也不直接删除其他候选。
- **覆盖先于保留判断**：分别核查窗口是否覆盖目标、采样是否取得目标、最终是否保留目标。定位失败、范围不足、时间分辨率不足与选择遗漏不能混为“补查无效”。瞬时事件在找到邻近锚点后也可能受益于细采。
- **时序关联不等于视觉相似**：对象延续、动作/状态变化、问题相关互补是不同层次；视觉相似不等于无用重复，视觉不同不等于信息增量。
- **四种证据需求允许共存**：清晰瞬间、局部连续过程、跨时间分散证据、全片概括。暂不把它们变成强制四分类及固定配额；保留多个有效位置，只给有依据的位置投入额外局部预算。

### 优先验证的技术手段

1. 定位端先复用完整1 FPS候选和原问题BLIP分数，检查对象、动作和“开头／首次／之后”等限定；避免一开始同时改查询、评分器和选择规则。
2. 从原问题提取已知对象/动作、时间限定、待确定属性及必要关系。103-1可要求“可辨认物体＋进入垃圾桶的联系”，不能预先写入答案“叉子”。这是结构化需求提取，不是原词受限改写；提取忠实性仍需验证。
3. 候选手段为复用LLaVA检查少量带时间编号的有序局部帧组，返回“可见／不可见／不确定”、支持帧编号和简短观察，而非未经校准的置信分数。不输入选项、标准答案或历史预测；先验证其能否区分直接线索、关系补充、主题重复和错误位置，再让它控制选择。额外多模态调用单独计账并纳入选帧成本，同模型判断偏差和幻觉必须披露。
4. 视觉特征、运动或跟踪只作为对象/场景连续性的辅助候选，不直接充当回答价值。暂不同时增加专用检索模型、全片两两关系打分或训练任务；若现有检查器不可靠，针对具体失效调整，不用一个新评分器替代所有判断。
5. 最终预算考虑单帧与小型互补帧组，比较新增信息与被替换旧信息的得失，不机械规定每锚点三帧、不预设可靠的统一证据效用公式。
