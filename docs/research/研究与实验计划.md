# 研究与实验计划

更新：2026-09-14。原公式首版已实现并完成开发50题四组探索：A/B/C/D为56%/60%/56%/56%，历史两组基线均58%。完整方法尚无净提升，作用机制与稳定性仍待验证。详见[方法首版结果](../experiments/video_mme_50/2026-09-14/method_v1/实验结果.md)及[实验进展记录](../experiments/实验进展记录.md)。下文保持本轮生效的原设计，不将优化提案写入配置。

## 研究场景

面向长视频问答，输入完整视频、问题及任务提供的答案选项，在固定最终帧预算下选择有效画面，交给冻结的视频视觉语言模型回答，同时考虑两类证据需求：

- **局部细节**：集中查看少数相关区域，保留清晰视角和关键状态。
- **全局覆盖**：覆盖多个相关事件，保留跨片段的信息。

混合或无法明确判断的问题采用折中策略。默认使用LLaVA-Video-7B、1 FPS初始候选、BLIP评分、最终16帧。目标是提高同预算问答效果；额外补查成本单独记录。

## 要解决的问题

均匀采样可能遗漏重点位置，Top-K可能集中于重复画面。核心假设是：

> 根据问题的证据范围，逐步分配片段覆盖与局部细节预算，再通过有限补查改善画面选择，能否提高同预算问答效果？

片段划分和MMR借用已有思想；拟研究的主要差异是**问题范围引导的预算竞争及其与条件补查的配合**。当前不预先宣称创新或有效性，也不将相似度、覆盖值直接解释为证据充分性。

## 核心方法论与原理解析

整体流程：`问题范围判断＋1 FPS全片扫描 → BLIP评分与候选分段 → 逐帧竞争16个名额 → 条件局部补查 → 固定配额段内重选 → 按时间排序 → VLM回答`。

### 1．问题范围判断

复用已加载的LLaVA，对原问题额外进行一次仅文本分类，不输入视频、答案或标准题型标签。固定分类提示词和贪心生成：

| 输出 | 含义 | 覆盖权重λ |
|---|---|---:|
| LOCAL | 主要需要某个局部目标或事件的细节 | 0.2 |
| GLOBAL | 需要跨多个事件收集或汇总信息 | 0.8 |
| MIXED | 同时需要定位与关系上下文，或无法确定 | 0.5 |

无法解析时使用MIXED并记录，不重复询问。标签只影响分配倾向，不排除任何片段；额外调用计入成本，不把标签或模型自评分当作可信概率。

### 2．建立候选片段

- 按1 FPS抽取候选，固定0.25秒采样相位，保存真实源帧位置和时间戳。
- 使用 `Salesforce/blip-itm-base-coco`，以原问题计算ITM匹配分数；第一版不加入选项聚合，标准答案不进入选择器。
- 使用BLIP视觉编码器的图像CLS特征，归一化后计算帧间余弦相似度，不使用图文交互后的文本特征。
- 借用WFS-SB独立分段器：db4小波、对称边界处理、分解漂移参数3、峰值高度系数0.5、突出度系数0.05、最小峰距 `max(5, floor(0.02N))`，其中N为初始候选数。只借用分段，不继承其片段过滤和预算分配。
- 全部有效片段参与竞争，无有效边界时将全片作为一个片段。边界与片段代表分数在初始扫描后固定；候选片段不等同于已确认的真实事件。

分段依据为WFS-SB的[官方核心代码](https://github.com/MAC-AutoML/WFS-SB/blob/main/wfs/core.py)与[官方配置](https://github.com/MAC-AutoML/WFS-SB/blob/main/configs/wfs_defaults.yaml)，实施时记录代码版本。

### 3．逐帧竞争预算

对尚未选择的帧i计算：

$$
G(i)=(1-\lambda)r_i+\lambda\frac{R_e}{1+n_e}-0.2D_i
$$

| 量 | 定义 |
|---|---|
| rᵢ | BLIP的0–1 ITM匹配分数，不重新进行全片最小—最大拉伸 |
| Rₑ | 所属片段在初始候选中的最高相关性 |
| nₑ | 所属片段已经选中的帧数 |
| Dᵢ | 与本片段已选帧的最大视觉相似度，截断到0–1；本段尚未选帧时为0 |

每段提出当前最高分候选，全局选出其中最高的一帧，更新该段状态，重复至16帧。同分按源时间、候选编号排序。覆盖奖励随本段已选帧数递减，允许片段获得零帧或多帧，不固定片段数量、不均分配额。所有分数均为选择代理指标，不解释为答对概率。

### 4．条件局部补查

粗选结束后，每个已获得配额的片段，取其已选帧中相关性最高者作为热点候选：

1. 热点相关性达到全片初始候选的第75百分位。
2. 在热点前后2秒内，用初始候选计算局部未覆盖程度：每帧相关性乘以其与该范围内已选帧的差异程度，再取平均。差异程度为1减去与这些已选帧的最大视觉相似度，相似度截断到0–1。
3. 未覆盖程度不大于10⁻⁶时跳过；其余按“热点相关性×局部未覆盖程度”降序排列，同分按时间排序。
4. 最多选择两个补查范围不重叠的热点；与已选范围重叠的热点跳过。

每处前后各2秒，补到4 FPS，采用与初始网格对齐的新增时间点并排除已有候选。每处最多12个新增候选，每题最多24个；仅补查一次，视频首尾裁剪到有效范围，按真实源帧去重，不补重复帧。

### 5．固定配额，段内重选

新增帧按真实时间归属初始片段。对已有配额且获得新候选的片段，在新旧候选并集中，使用与粗选一致的相关性和局部重复惩罚重新选满原配额。

片段边界、Rₑ及各段配额保持不变；零配额片段不因补查获得新名额。新帧没有优先权，最终仍为16个不同帧，按源时间排序输入VLM。

本版补查改善已关注区域的画面，不能保证挽救完全遗漏的片段；按代理准则重选也不保证真实答题效果提高。

## 实验配置

| 项目 | 首版设置 |
|---|---|
| 候选采样 | 1 FPS，0.25秒相位，保留真实源时间戳 |
| 默认问答模型 | LLaVA-Video-7B-Qwen2（`lmms-lab/LLaVA-Video-7B-Qwen2`） |
| 候选问答模型 | LLaVA-Video-7B、LLaVA-OneVision-7B、Qwen2.5-VL-7B-Instruct、Qwen3-VL-8B-Instruct |
| 相关性评分器 | `Salesforce/blip-itm-base-coco`，仅使用原问题；后续再比较CLIP |
| 最终帧预算 | 首版16帧；后续覆盖8／16／32／64帧 |
| 默认基线 | 均匀采样、BLIP全局Top-K |
| 数据规模 | 原版Video-MME、LongVideoBench、MLVU，每个数据集50题开发、150题预留；抽样规则见实验进展记录 |
| 初期范围 | 先在Video-MME开发50题验证，再检查其他数据集 |
| 补查上限 | 每题最多两个热点，前后各2秒、4 FPS，新增候选最多24帧 |
| 成本记录 | 文本分类、解码、BLIP评分、选择、问答及端到端时间，区分首次处理和缓存复用 |
| 输入控制 | 使用对应模型的官方预处理；同模型同题同预算保持尺寸、视觉Token、提示词和生成设置一致 |

均匀与Top-K基线使用初始1 FPS候选池；Top-K按BLIP分数取最高的K个唯一候选，再恢复时间顺序，不附加MMR。Top-K与研究方法使用相同评分器和可用查询信息。

新增候选仅属于补查阶段，不能将完整方法与基线描述为始终使用完全相同的候选池。模型、数据和预算扩展另行制定执行计划，本次不启动；具体输入接口、提示词及代码版本在执行协议中固定。

## 实验设置与效果

| 比较 | 要回答的问题 | 状态 |
|---|---|---|
| 完整方法 vs 均匀采样、BLIP全局Top-K | 同为16帧时，本方法是否改善答题效果 | C为56%，两组历史基线均58% |
| 固定λ=0.5 vs 问题自适应λ，均关闭补查 | 问题范围判断是否改善预算分配 | A为56%，B为60%；作用存在耦合 |
| 自适应方法关闭 vs 开启补查 | 有限局部补查是否提供额外收益 | B为60%，C为56%；0改善/2退化 |
| Top-K在完整方法实际扩充后的同一候选池上重选 | 收益是否主要来自新增候选 | D为56%；相对旧Top-K 0改善/1退化 |

最后一项是候选池诊断，获取成本包含产生补查位置的开销，不作为独立部署算法报告。均匀采样不承担无需执行的BLIP评分成本；问题自适应方法的额外文本分类需计入成本。

验收覆盖无有效分段、同分排序、候选不足、分类解析失败、静止画面不触发补查、热点区间重叠、视频首尾、源帧去重，以及补查前后配额不变。候选不足以满足固定预算或输入异常时停止报告，不静默降预算。

分别报告各数据集准确率、逐题配对得失与置信区间、补查触发率、新帧进入最终输入的比例，以及视觉Token、耗时、显存和固定规则案例。小样本差异不作为稳定优势或等效证明。

**阶段结果：两组基线和首版四组完成。** 基线均29/50；A/C/D均28/50，B为30/50。B-A改善2题，C-B恰好退化相同2题；所有已报告配对区间包含0。A/B/C每题平均E2E约49.570/49.633/50.541秒，D归因成本约50.615秒。补查49/50题触发，25题的42张被替换粗帧距窗口超过1秒，表明整段重选存在非局部作用。完整证据及局限见[方法首版结果](../experiments/video_mme_50/2026-09-14/method_v1/实验结果.md)，不是完整评测集成绩。

**阶段判断：完整方法尚未证实有效。** B可作为下一轮工作参考；优先讨论窗口外粗证据保护，再单独验证λ解耦。首轮结果冻结，优化提案未实施，不按单题输赢改样本或使用预留集调参。
