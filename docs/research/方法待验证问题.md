# 方法待验证问题

此处集中维护仍有效的研究讨论，来自此前review；不是已接受的新方法。已确认公式与参数以[研究与实验计划](研究与实验计划.md)为准，历史背景见[资产核验记录](../archive/环境与资产核验_20260914.md)。

- 当前λ同时影响覆盖奖励和相关性权重，使重复惩罚相对相关性的比例从LOCAL的0.25变为GLOBAL的1。曾讨论改成 `rᵢ＋β(q)Rₑ/(1+nₑ)−γDᵢ`，但未确认，不自行替换公式或设新参数。
- 覆盖项可解释为 `Σ Rₑ H(nₑ)` 的边际增量；加上最大相似度惩罚后，尚未建立完整集合目标和近似保证，不能宣称最优。
- 候选片段不等于真实事件。分段粒度会影响首帧覆盖奖励，可能导致预算倾向改变。
- 局部未覆盖指标来自已抽候选，尚未证明能预测未采样时刻的收益；固定配额补查无法恢复零配额区域。
- 后续实验需分别验证范围适配与局部补查，并通过扩充候选池上的Top-K诊断区分新增候选的贡献。超过均匀和Top-K本身不足以证明优于已有工作。
