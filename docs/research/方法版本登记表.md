# 方法版本登记与命名规范

2026-09-22统一启用。当前工作基准为 **RD-1.2**，旧称“E1正式两遍流程／RD-2P v1.0”，对应已完成125/200的同一实现，改名不产生新的算法或成绩。机器登记源为[method_versions.json](../../configs/method_versions.json)；修改登记后同步本表和现行索引。

## 固定版本

| 统一名称 | 历史别名 | 核心规则与关系 |
|---|---|---|
| BASE-Uniform | 均匀采样 | 时间位置均匀选帧；帧预算等输入协议另行冻结 |
| BASE-BLIP-TopK | Top-K、TopK | 原问题BLIP全局Top-K |
| SB-1.0 | A | 固定λ=0.5，不补查 |
| SB-1.1 | B | 自适应λ，不补查；父版本SB-1.0 |
| SB-1.2 | C | 自适应λ、条件补查、整段重选；父版本SB-1.1 |
| SB-1.3 | E、C-local | 局部受限重选；父版本SB-1.2 |
| RB-1.0 | R | 独立的Top-K区域边界取证系列 |
| RD-1.0 | 密度v1、Density-v1 | 固定密度权重＋视觉差异竞争 |
| RD-1.1 | soft、软折中 | 在RD-1.0上加入种子视觉支持 |
| RD-1.2 | E1正式版、RD-2P v1.0 | 在RD-1.1基础上采用两遍选择；递减密度预算＋固定配额距离排序 |

SB表示分段预算竞争（Segment Budgeting），与外部论文WFS-SB不是同一名称。RB表示区域边界取证（Region Boundary），RD表示检索密度引导（Retrieval Density）。编号表示归档与演进关系，不保证后一个版本效果更好，也不表示旧版本已废弃。

## 探索与诊断

| 统一名称 | 历史别名 | 范围、依赖与当前状态 |
|---|---|---|
| SB-1.2-diag01 | D | 在SB-1.2扩充池上做Top-K；是候选池诊断，不是独立部署方法 |
| SB-1.3-exp01 | Q | 受限查询；阶段归属SB-1.3，但选择侧实际复用SB-1.1，不启用C-local补查；未接入 |
| RD-1.1-exp01 | P1 | 局部L×u、跨区w×u；仅归因对照 |
| RD-1.1-exp02 | D1 | 密度奖励递减；后被RD-1.2采用 |
| RD-1.1-exp03 | E1离线诊断 | 固定exp02实际配额，局部距离排序；依赖exp02产物，后被RD-1.2采用 |
| RD-1.2-exp01 | 七题推广入口人工修复 | 人工标记、两组粗候选；不是自动检测器，无问答成绩 |
| RD-1.2-exp02 | 64帧单帧推广资格识别 | 辅助识别能力测试；存在关键证据误排，未接入正式选择 |

原局部排序/扩窗检查、固定输入重复性检查、逐帧审计、区域有效性盘点是分析任务，不再为每个工具新造算法版本。它们用任务名和运行编号追溯；使用的基础版本必须明确。

E1不得脱离上下文使用：离线固定配额诊断是RD-1.1-exp03；从原视频重新计算配额并问答的正式实现是RD-1.2。A/B/C/D/E也是历史SB组别，不可全局替换为方法名称——它们同时可能是答案字母、变量或其他实验的局部编号。

## 后续命名规则

1. 冻结方法用“系列-主版本.次版本”，如RD-1.2；独立框架变化才讨论新主版本/系列。版本号不自动宣称收益。
2. 从冻结版本出发的改动用“父版本-exp两位序号”；专门归因对照用diag。编号分配后不复用，失败也保留原号，并登记状态。
3. 后续RD-1.2探索从exp03继续，尚未分配具体规则或执行；确认范围时先登记。成熟探索升为新冻结版本时保留其原探索记录和实际依赖。
4. 数据规模不进入方法版本号。运行另记，例如`rd_1_2__videomme2700__20260922__r01`；这是格式示例，不表示全量测试已启动。新运行不覆盖旧目录。
5. 新方案、报告标题、对照表、图例及结果元数据优先写统一ID；首次出现可括注历史别名。结果元数据应区分`method_version`、`run_id`、样本清单、代码/配置哈希。
6. 本表、机器登记、研究计划和实验索引一起维护。不能只改一个展示名称而默默改变算法或来源。

## 兼容与冻结边界

- 不重命名历史源码/CLI、内部variant字段、结果JSON键、运行目录、代码快照或历史Git提交。旧字段通过明确上下文映射到统一ID，不改写原始证据。
- 现行入口文档用统一名；历史报告保留原表格、公式及分组，并在开头给出本轮名称映射。不得替换答案A/B/C/D或代码路径中的标识符。
- [RD-1.0原设计稿](检索密度引导的条件补查与选帧框架.md)本身被四轮实验纳入哈希，因此保留原文中的“v1.0”，本表及索引负责映射。它不是当前RD-1.2规则说明。
- [旧技术登记](../../configs/releases/rd2p_v1_0.json)及其`release_id=rd2p_v1_0`保持原样；新展示名称以本登记的RD-1.2为准。没有创建新Git tag，也没有新测成绩。

完整实验入口见[实验索引](../experiments/README.md)，各方法结果报告位置见机器登记的`report`字段；当前两遍流程见[RD-1.2正式记录](../experiments/video_mme_200/2026-09-22/density_e1/实验记录.md)。
