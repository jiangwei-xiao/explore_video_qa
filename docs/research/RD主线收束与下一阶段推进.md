# RD主线收束与下一阶段推进

更新日期：2026-10-19。状态：执行训练充分性与监督适配CPU诊断；新增大模型调用0，原200题验证结果封存。本页是近期讨论、执行与复盘的统一工作入口；[研究与实验计划](研究与实验计划.md)保留顶层研究入口，具体实验协议、原始返回和统计继续各自归档。

## 一、目标与已确认原则

最终目标是提高同预算全量视频问答的净收益，并同时检查新增正确与原有正确题退化。当前保留RD-1.2、exp07、exp12及两基线的冻结实现和结果，分别作为工程及方法参照。

已确认的近期收束：

1. 保留已验证的检索定位、全片粗候选和精确局部采样能力。定位分数是取证入口，不能自动代表回答价值。
2. 重新研究选择层的价值依据：区分对象/主题相关、可见状态、文字、动作阶段与关系完整性；新增信号必须说明比现有视觉相似度多提供什么。
3. 重新审查区域和前缀的职责。区域能组织候选和补查，但其对支持、去重、锚点和预算的连带约束需要独立论证。解除约束也必须配合合适的目标。
4. 暂停现有余弦、差异指数、覆盖权重和替换阈值周围的连续补丁。下一项研究应明确改变表示、基本观察单位或价值依据中的一个核心假设。
5. 大模型骨干保持冻结。此前免训练事实观察阶段已经结束；2026-10-19按当前确认允许一次轻量监督学习，只训练约10万参数的集合评分头。不得把辅助生成、人工构造银行或诊断纠错当作算法准确率；正式方法公开预算仍仅K。

每轮启动前先读本页，说明所研究的问题对应哪项判断。已确认原则、工作假设和实际结果分别标注；工作假设不能因代理指标提高直接升级为原则。新增实验若超出当前问题，先解释为什么需要改变主线。本页维护当前任务与简短决策，长实验细节只引用报告。

### 结构性疑点，尚非理论上限证明

- 同一BLIP/CLS相似度反复参与支持、重复度和覆盖，缺少对回答所需事实的独立判断。
- 局部规则在特定条件下化为`s×sqrt(1−s)`，偏好适度相似的外观；该偏好不蕴含答题信息增量。
- 固定前缀限制可选集合，覆盖目标也可能偏好无用画面；仅精确求解或混合exp07/12权重不能自动修复二者。
- 时间密集、窗口合并和最近归属不等同于语义事件；区域一次误定位可影响多个下游决策。
- 必要线索仍在时，整组输入与Qwen时间patch伙伴变化也可能改变回答。不能把所有退化解释为证据被删。

工作判断：现有代理量和约束构成的方法族出现明显边际收益递减；这不等于证明选帧方法的精度上限。最近30多个编号包含离线探针、消融及不同规模试验，不能视为30次独立框架否证。

## 三、当前唯一任务：训练充分性与监督适配诊断

已确认问题：原40次更新不足以区分训练不足、反馈稀疏和泛化不足。当前只用既有600题训练资产与历史四策略结果，不评估原200题的新检查点。

- 先描述NExT-QA训练600题和Video-MME/MLVU四工作点的监督密度、输入差异、银行互补和时长/任务分母；目标结果不参与小头训练或参数选择。
- 同一原评分头/损失/优化器从种子2027重放40步，参数与优化器误差≤1e-6且训练选择一致后，沿单条轨迹最多2000步。
- 每20步只检查有效训练题的偏好和最高分答对率，均≥95%连续3次即停止；未通过则本轮不运行CV。
- 通过后在原训练600题内按视频固定五折，每折独立初始化、训练480/留出120；相同2000步上限和训练停止规则，留出标签不参与择模。最多6轨迹、12000步。
- 交付CPU训练/梯度/分数曲线、条件性600题折外结果及监督适配结论。新增BLIP/视觉骨干/生成/QA均0，完成后统一review，不自动扩监督或原基准测试。

执行、停止与恢复规则见[本轮协议](../experiments/nextqa/2026-10-19/set_value_trainability/执行协议.md)。

### 已完成：800题轻量集合价值学习

工作假设：不再把外观相似度或生成描述直接当作回答价值，而是使用冻结教师的实际问答反馈，学习同题不同完整帧组之间的偏好。该假设尚未验证；本轮只比较四个既有输入，不是新的逐帧选择算法。

- NExT-QA官方train/val按视频独立选择300/100视频、各两题，形成600训练/200验证；不使用官方test，也不以已有模型对错抽样。源身份、内容SHA及8帧近重复指纹排查与Video-MME/MLVU以及新数据间的重叠。教师预训练重叠未排除，不称教师未见测试。
- 每题固定BASE-Uniform、BASE-BLIP-TopK、RD-1.2-exp07、RD-1.2-exp12四组K8输入。原选择规则和模型骨干不变；最多3200次真实教师QA、8次合成，同题完整实际输入相同才能共享。
- 每帧表示仅包含冻结BLIP的问题融合CLS、ITM及相对真实时间；小头使用逐帧共享映射、均值/最大值汇聚及集合标量输出，不输入选项、标准答案、方法ID或历史预测。
- 仅从训练题构造同题答对/答错组的排序监督。相同输入不重复投票，全对/全错不制造偏好。固定FP32、AdamW、20epoch，使用最后一轮，不通过验证分数选择模型。
- 首次验证问答前冻结200题的候选分数、最终选择及检查点哈希。验证答案不回流训练；与训练选出的最佳固定方法、四个固定方法和平均ITM选择规则比较。

当前阶段：固定训练和验证均已结束。验证学习160/200，较事前训练选出的exp07多2题、较验证均匀少2题；训练/验证偏好正确率58.51%/42.11%，有效题47/19。原始生成独立复算和8435文件完成恢复通过，新增生成0。随机seek异常在正式QA前通过本轮专用顺序读取修正，保留同一800题与旧失败；448个父准备输入RGB/源顺序一致。参数和修正见[协议](../experiments/nextqa/2026-10-19/set_value_learning/执行协议.md)，分母、配对区间和决定见[结果](../experiments/nextqa/2026-10-19/set_value_learning/实验结果.md)。

### 已结束任务：单帧事实最小接口验证

工作假设：将来源关联交给程序、观察任务收缩为单帧可见内容，能更清楚判断事实识别是否可用。旧接口的编号/限定错误并不自动说明局部事实完全不可提取；程序绑定来源也不自动证明事实正确。

- 原12题24组固定取第2/4帧，共48张（Video-MME32、MLVU16），与旧单帧逐图对照；图片已观察，不作为独立泛化样本。
- 保持旧单帧官方视频处理与原像素。模型只看原问题及单图，源编号、PTS和时间仅留程序日志。
- 输出仅`visible_text`和`observations`两个字符串数组，每数组最多3项；不要求生成关系或全片限定判断。
- 每图事前冻结≤3项可见目标，跨帧变化不算单帧事实；旧输出内容用同一依据复评，旧编号错误单列。
- 一次固定提示，48真实辅助＋最多2合成、最终QA/BLIP/补查/独立特征新增0。BF16/FA2、贪心、batch1、种子2027、256新Token；最多2卡后台独立运行。
- 原文保留，固定允许完整单层JSON/无语言围栏；不补字段或重试。标注及输出复核≤60分钟。

当前状态：已完成48辅助＋2合成、最终QA0，恢复新增0。输入像素逐图一致、1088测试通过/1跳过。有效输出40/48、有效内容正确率81.73%、操作性召回43.18%，三项均未达门槛。忽略格式的同图内容正确率55.81→81.99%、召回55.30→59.47%，但主要收益是文字，物体/状态没有稳定提升，更多明确目标被省略。详见[结果](../experiments/cross_dataset/2026-10-18/single_frame_facts/实验结果.md)与[协议](../experiments/cross_dataset/2026-10-18/single_frame_facts/执行协议.md)。

## 四、后续决策与本轮结束点

当前CPU诊断以40步重放、训练充分性、条件性折外收益三层作判断；拟合通过但折外无改善时保留泛化不足结论。若折外偏好≥60%、相对训练折固定策略净增、≥3视频改善，且不低于四固定策略最好结果，仅支持讨论下一轮独立监督扩展。本轮不执行扩展。以下保留原800题试点的事前门槛及停止结论。

当前学习试点的投入判断：验证集相对训练选出的最佳固定方法净增至少4题、改善来自至少3视频、逐题平均偏好正确率至少60%，且不低于验证集四固定方法最好成绩。全部报告配对得失及100视频簇重抽区间；不将这些门槛当作显著性证明。

若训练拟合而验证无收益，记录过拟合或信号不足，不扫描网络/损失/训练轮数；若没有同题正负差异，允许在监督信号不足处分支停止。完成后统一review；不自动测试Video-MME/MLVU、不登记exp35、不升级默认RD。

本轮决定：未达净增4题、偏好60%和不低于验证最好固定方法三项要求，结束固定实现。47题有效监督只产生40个优化更新，训练损失0.69317→0.68500，不能只归为过拟合；候选银行、监督密度与表示/训练可辨识性仍未分清。下一步先review这些条件，不自动增加训练轮次、换头、扩原数据集或回到窗口/余弦补丁。

以下为已结束单帧观察任务的原判断及结论，保留历史边界：

先核查事实及真实图像来源，再比较同48图的新旧内容。事实召回只在事前可见目标上计分；正例空输出召回0，无目标图单列虚构风险。模型自己写的置信度不作为评价。

本轮投入门槛：有效输出≥46/48、可核查陈述正确率≥90%、已列可见事实宏平均召回≥80%。文字/物体/状态分项及具体虚构另列。门槛是资源判断，不是显著性保证；不将消除模型编号输出记成视觉能力提升。

| 结果 | 结束时的决策 |
|---|---|
| 单帧内容达到门槛 | 保留接口，提出下一层证据单元设计供review；不直接启动问答小测/全量 |
| 内容与旧接口接近 | 只认可溯源及接口简化，不宣称新增识别能力 |
| 只有某类局部事实可靠 | 明确文字/属性等适用范围，不能承担通用关系判断 |
| 内容仍不可靠 | 结束当前固定实现，不扫描提示词或追加调用 |

本轮结束点是单帧能力结论与适用边界。此前帧组固定实现已结束；当前最小单帧诊断是经用户确认的新任务，不分配exp35，不修改RD公式，结果出来后统一review。

单帧阶段决策：结束本固定单帧接口，不放宽数组规则或继续扫描提示。程序关联来源是工程属性，不能替代事实正确性。局部文字可读的线索继续保留，但现有事实信号不足以直接统一exp07/12；该阶段未自动启动选择层、小测或全量。

历史观察路线若恢复，仍需依次确认观察可靠性、证据单元及统一目标；不能跳过第一项。当前只推进本页第三节的集合学习试点，不并行改动RD算法。
