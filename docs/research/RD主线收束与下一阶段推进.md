# RD主线收束与下一阶段推进

更新日期：2026-10-16。状态：帧组事实观察诊断完成，当前固定实现未通过；停止接入选择层，等待统一review。本页是近期讨论、执行与复盘的统一工作入口；[研究与实验计划](研究与实验计划.md)保留顶层研究入口，具体实验协议、原始返回和统计继续各自归档。

## 一、目标与已确认原则

最终目标是提高同预算全量视频问答的净收益，并同时检查新增正确与原有正确题退化。当前保留RD-1.2、exp07、exp12及两基线的冻结实现和结果，分别作为工程及方法参照。

已确认的近期收束：

1. 保留已验证的检索定位、全片粗候选和精确局部采样能力。定位分数是取证入口，不能自动代表回答价值。
2. 重新研究选择层的价值依据：区分对象/主题相关、可见状态、文字、动作阶段与关系完整性；新增信号必须说明比现有视觉相似度多提供什么。
3. 重新审查区域和前缀的职责。区域能组织候选和补查，但其对支持、去重、锚点和预算的连带约束需要独立论证。解除约束也必须配合合适的目标。
4. 暂停现有余弦、差异指数、覆盖权重和替换阈值周围的连续补丁。下一项研究应明确改变表示、基本观察单位或价值依据中的一个核心假设。
5. 下一阶段先免训练、冻结模型，在能力验证后统一review。不得把辅助生成、人工构造银行或诊断纠错当作算法准确率；正式方法公开预算仍仅K。

每轮启动前先读本页，说明所研究的问题对应哪项判断。已确认原则、工作假设和实际结果分别标注；工作假设不能因代理指标提高直接升级为原则。新增实验若超出当前问题，先解释为什么需要改变主线。本页维护当前任务与简短决策，长实验细节只引用报告。

### 结构性疑点，尚非理论上限证明

- 同一BLIP/CLS相似度反复参与支持、重复度和覆盖，缺少对回答所需事实的独立判断。
- 局部规则在特定条件下化为`s×sqrt(1−s)`，偏好适度相似的外观；该偏好不蕴含答题信息增量。
- 固定前缀限制可选集合，覆盖目标也可能偏好无用画面；仅精确求解或混合exp07/12权重不能自动修复二者。
- 时间密集、窗口合并和最近归属不等同于语义事件；区域一次误定位可影响多个下游决策。
- 必要线索仍在时，整组输入与Qwen时间patch伙伴变化也可能改变回答。不能把所有退化解释为证据被删。

工作判断：现有代理量和约束构成的方法族出现明显边际收益递减；这不等于证明选帧方法的精度上限。最近30多个编号包含离线探针、消融及不同规模试验，不能视为30次独立框架否证。

## 三、当前唯一任务：帧组事实提取能力诊断

**核心假设**：冻结模型对相同画面输出可核查事实、来源帧和未确认限定，可能提供视觉相似度之外的有效信息；联合观察四帧可能比逐帧输出并集更好地表达状态与关系。

这是假设，不预设有效。本阶段使用诊断任务名称，不分配exp35、不选择最终帧、不修改RD公式；完成后review是否值得进入选择层。

- 固定12题：Video-MME 012-3、035-2、103-1、113-3、383-2、386-1、538-1、584-3；MLVU Q8、Q866、Q624、Q367。
- 同一题的冻结Qwen32合法池构造见证组和实际选择对照组，各4帧。前者保留旧审计见证并按真实时间最近补齐；后者取exp12已选且不在见证组中的原分数Top-4粗帧。对照可能也有有效事实。
- 在模型运行前冻结最多3项可见事实、1项关系及限定范围判断；每项指向具体源帧。不确定项留痕，模型输出后不改写真值。
- 用冻结Qwen2.5-VL-7B、BF16/FA2、官方视频处理及原像素范围，原问题＋画面编号＋真实源时间生成观察。不给选项、标准答案、人工标签或旧对错。
- 每组4次单帧＋1次四帧，共120次真实辅助生成，另最多4次合成；贪心、batch1、种子2027、最多256新Token。最终QA、BLIP、补查和额外视觉特征调用均0。
- 输出固定JSON：`observations`、`relations`、`unverified_constraints`；最多4项观察、1项关系。逐条引用可用帧编号，不把局部内容扩展成未展示的全片事实。
- 人工标注与输出初审累计≤90分钟；未审核项不算通过。真实生成前冻结源/RGB、模型、提示和评价文件；已开始失败占额度，未知生成/OOM/身份异常暂停，答错或格式失败不重发。

协议和结果归档到`docs/experiments/cross_dataset/2026-10-16/evidence_observation/`；原始资产留独立`outputs/diagnostics/`运行目录。

**当前状态：已完成并收尾。** [完整结论](../experiments/cross_dataset/2026-10-16/evidence_observation/实验结果.md)：24组/96唯一源帧、120辅助＋4合成、最终QA0，恢复0新增生成。严格JSON为0/24及0/96，不能事后去围栏宣称通过。单独内容初审中，73/96单帧输出引用未提供ID；联合观察存在组内错帧绑定、未展示关系及限定遗漏。要求来源正确的观察宏平均40.63%、已列可见事实召回42.86%（21组）、限定4/22；这些只是补充解释，不替换正式失败计分。部分属性/文字能读出，尚未建立可靠帧组增量。

## 四、后续决策与本轮结束点

先核查格式、事实、来源、关系及限定范围，再与相同四帧的逐帧输出并集比较。事实召回只在事前可见且已核实的事实项上计分，不将未展示事实当作模型漏识。模型自己写的置信度不作为评价。

投入门槛：帧组有效JSON≥22/24，可核查观察正确比例≥90%，已列可见事实宏平均召回≥80%，限定范围判断≥80%正确；并在≥3个独立视频出现联合观察增量，其中≥1个来自MLVU。门槛是资源判断，不是显著性保证；单例风险计入结果，不自动否定整个方向。

| 结果 | 结束时的决策 |
|---|---|
| 事实可靠、联合观察有增量 | 提出事实→证据单元→组合目标的设计供review，不直接启动开发或全量 |
| 事实可靠、联合观察无增量 | 保留单帧事实提取线索，不强行采用帧组 |
| 局部事实可靠、限定不可靠 | 只认可局部观察能力，不能承担全局关系/次数判断 |
| 事实本身不可靠 | 结束该固定观察器，说明缺少什么能力，不临时更换提示通过门槛 |

当前决策：结束这套固定提示/输入/输出观察器，不进行第二版、不启动开发或全量；保留局部可见事实能力线索，不否定整个事实路线。后续首先review来源绑定及观察范围的最小可靠接口，未确认前不直接设计事实组合目标或分配exp35。该方向仍是工作假设，不是已确认的新方法。

当前不并行推进其他算法改动。后续需讨论的问题依次是：观察可靠性是否成立；可靠观察怎样成为可选证据单元；何种统一目标与约束能服务同预算回答。未验证第一项前不先写后两项的正式公式。
