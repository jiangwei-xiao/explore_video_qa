# RD主线收束与下一阶段推进

更新日期：2026-10-18。状态：执行已确认的单帧事实最小接口验证，先核对48张图的内容可靠性。本页是近期讨论、执行与复盘的统一工作入口；[研究与实验计划](研究与实验计划.md)保留顶层研究入口，具体实验协议、原始返回和统计继续各自归档。

## 一、目标与已确认原则

最终目标是提高同预算全量视频问答的净收益，并同时检查新增正确与原有正确题退化。当前保留RD-1.2、exp07、exp12及两基线的冻结实现和结果，分别作为工程及方法参照。

已确认的近期收束：

1. 保留已验证的检索定位、全片粗候选和精确局部采样能力。定位分数是取证入口，不能自动代表回答价值。
2. 重新研究选择层的价值依据：区分对象/主题相关、可见状态、文字、动作阶段与关系完整性；新增信号必须说明比现有视觉相似度多提供什么。
3. 重新审查区域和前缀的职责。区域能组织候选和补查，但其对支持、去重、锚点和预算的连带约束需要独立论证。解除约束也必须配合合适的目标。
4. 暂停现有余弦、差异指数、覆盖权重和替换阈值周围的连续补丁。下一项研究应明确改变表示、基本观察单位或价值依据中的一个核心假设。
5. 下一阶段先免训练、冻结模型，在能力验证后统一review。不得把辅助生成、人工构造银行或诊断纠错当作算法准确率；正式方法公开预算仍仅K。

每轮启动前先读本页，说明所研究的问题对应哪项判断。已确认原则、工作假设和实际结果分别标注；工作假设不能因代理指标提高直接升级为原则。新增实验若超出当前问题，先解释为什么需要改变主线。本页维护当前任务与简短决策，长实验细节只引用报告。

### 结构性疑点，尚非理论上限证明

- 同一BLIP/CLS相似度反复参与支持、重复度和覆盖，缺少对回答所需事实的独立判断。
- 局部规则在特定条件下化为`s×sqrt(1−s)`，偏好适度相似的外观；该偏好不蕴含答题信息增量。
- 固定前缀限制可选集合，覆盖目标也可能偏好无用画面；仅精确求解或混合exp07/12权重不能自动修复二者。
- 时间密集、窗口合并和最近归属不等同于语义事件；区域一次误定位可影响多个下游决策。
- 必要线索仍在时，整组输入与Qwen时间patch伙伴变化也可能改变回答。不能把所有退化解释为证据被删。

工作判断：现有代理量和约束构成的方法族出现明显边际收益递减；这不等于证明选帧方法的精度上限。最近30多个编号包含离线探针、消融及不同规模试验，不能视为30次独立框架否证。

## 三、当前唯一任务：单帧事实最小接口验证

工作假设：将来源关联交给程序、观察任务收缩为单帧可见内容，能更清楚判断事实识别是否可用。旧接口的编号/限定错误并不自动说明局部事实完全不可提取；程序绑定来源也不自动证明事实正确。

- 原12题24组固定取第2/4帧，共48张（Video-MME32、MLVU16），与旧单帧逐图对照；图片已观察，不作为独立泛化样本。
- 保持旧单帧官方视频处理与原像素。模型只看原问题及单图，源编号、PTS和时间仅留程序日志。
- 输出仅`visible_text`和`observations`两个字符串数组，每数组最多3项；不要求生成关系或全片限定判断。
- 每图事前冻结≤3项可见目标，跨帧变化不算单帧事实；旧输出内容用同一依据复评，旧编号错误单列。
- 一次固定提示，48真实辅助＋最多2合成、最终QA/BLIP/补查/独立特征新增0。BF16/FA2、贪心、batch1、种子2027、256新Token；最多2卡后台独立运行。
- 原文保留，固定允许完整单层JSON/无语言围栏；不补字段或重试。标注及输出复核≤60分钟。

当前状态：代码、输入与评价准备中，尚无新能力结论。协议见[单帧验证](../experiments/cross_dataset/2026-10-18/single_frame_facts/执行协议.md)。旧帧组诊断结果保留，详见第二节链接。

## 四、后续决策与本轮结束点

先核查事实及真实图像来源，再比较同48图的新旧内容。事实召回只在事前可见目标上计分；正例空输出召回0，无目标图单列虚构风险。模型自己写的置信度不作为评价。

本轮投入门槛：有效输出≥46/48、可核查陈述正确率≥90%、已列可见事实宏平均召回≥80%。文字/物体/状态分项及具体虚构另列。门槛是资源判断，不是显著性保证；不将消除模型编号输出记成视觉能力提升。

| 结果 | 结束时的决策 |
|---|---|
| 单帧内容达到门槛 | 保留接口，提出下一层证据单元设计供review；不直接启动问答小测/全量 |
| 内容与旧接口接近 | 只认可溯源及接口简化，不宣称新增识别能力 |
| 只有某类局部事实可靠 | 明确文字/属性等适用范围，不能承担通用关系判断 |
| 内容仍不可靠 | 结束当前固定实现，不扫描提示词或追加调用 |

本轮结束点是单帧能力结论与适用边界。此前帧组固定实现已结束；当前最小单帧诊断是经用户确认的新任务，不分配exp35，不修改RD公式，结果出来后统一review。

当前不并行推进其他算法改动。后续需讨论的问题依次是：观察可靠性是否成立；可靠观察怎样成为可选证据单元；何种统一目标与约束能服务同预算回答。未验证第一项前不先写后两项的正式公式。
