# 证据审计工具

审计只读历史结果，未导入问答后端或评分器。新实现位于 `src/videoqa_audit/`，不修改 `videoqa_runtime/` 和 `videoqa_methods/`，不会改变旧实验指纹。

## 目录与接口

| 模块 | 职责 |
|---|---|
| core.py | 配对/PTS/Token验证、CPU渲染、匿名页面、复核导入 |
| observations.py | 将人工明确填写的联合图板编号标签映射到真实PTS；缺项拒绝完成 |
| context.py | 原片窗口，从文件起点恢复精确源帧号 |
| report.py | 50题/300组/4800槽位CSV，B/C集合差与A/B配额变化 |
| review.html | 无服务器离线复核，浏览器暂存和JSON导出 |

新增接口均有中文说明和步骤注释。首批手工观察位于运行目录 `pilot_observations.json` 与 `observations/`，不是根据BLIP或正确率生成的标签。

## 运行

在远端仓库根目录，使用 `/App/conda/envs/explore_video_qa/bin/python`，下文简称python：

```bash
python scripts/audit_evidence.py prepare \
  --source outputs/methods/method_v1_videomme50_20260914_r1 \
  --out outputs/analysis/evidence_videomme50_20260915_r1 \
  --requirements configs/evidence_requirements_v1.json

nohup setsid python -u scripts/audit_evidence.py render \
  --out outputs/analysis/evidence_videomme50_20260915_r1 \
  > outputs/analysis/evidence_videomme50_20260915_r1/render.log 2>&1 < /dev/null &

python scripts/render_evidence_context.py \
  --out outputs/analysis/evidence_videomme50_20260915_r1 \
  --spec configs/evidence_pilot_windows.json

python scripts/audit_evidence.py report --out outputs/analysis/evidence_videomme50_20260915_r1
python scripts/audit_evidence.py import-review \
  --out outputs/analysis/evidence_videomme50_20260915_r1 --review /实际路径/004-3.review.json
```

已渲染题以 `frames/<qid>/complete.json` 跳过；完成标记之前的中断题重新渲染，不触及人工标注。并发渲染由文件锁拒绝。prepare只接受完全相同的结果和需求；不要用重新prepare覆盖需求修订。

## 复核与保存

用浏览器打开运行目录 `index.html`，点首批题号；选择匿名G1–G6组，查看384输入和原始PNG。先填写自己的范围/证据判断，再按需显示初审。填写内容在浏览器localStorage暂存，但必须导出JSON后交回，不能把暂存当作服务器持久化。

导入按协议哈希、题号、组、PTS和枚举验证；相同内容幂等保存到 `reviews/`。不覆盖助手初审，不自动裁决分歧。空白不纳入一致率分母。

提交前review补充：新复核页面在导出中绑定 `initial_annotation_sha256`。导入时使用匹配的当前或历史初审版本计算一致率，避免后续修订污染比较。旧页面、旧草稿或找不到对应版本的复核仍会保存，但一致率为null并注明原因，不自动绑定到新版本。更改页面后如存在旧浏览器草稿，会保留草稿并提示版本问题。

验收器根据实际未审题数生成状态；即使50题原帧初审完成，也不自动认定384可见性、用户复核和机制分析已完成。历史运行快照保持原样，本次代码修复不回写旧验收报告。

## 状态边界

`initial_reviewed`表示原帧图板初审完成，不代表原片全覆盖、384全部可读、用户已复核或假设已证实。具体384抽查范围见 `input_visibility.json`，其他项仍需继续审核。结果汇总保留pending计数，禁止当作无关或不确定。首批报告发布后等待用户校准，剩余40题不自动标注。
