# RD-1.2-exp33：单次邻接修复与双数据集小测

## 目标及父参照

将已验证的人工邻接干预转为一个自动规则，检验固定预算下能否改善回答并保护原有正确题。唯一父参照为RD-1.2-exp12；exp07及两基线保留对照，四个单元使用同一机制。先完成9748个配置的零模型离线检查，通过证据门槛后执行Video-MME200／MLVU210的LLaVA8与Qwen32，共820条方法结果，最多820次新问答；本轮不自动全量。

## 冻结选择规则

1. 精确读取父版有序输入及原合法池，公开预算仅K。原种子、窗口、补查、前缀和DP保持其冻结计算。
2. 每个已保留粗帧a都可提出请求，不限于种子。若候选池中a的直接时间前驱或后继已入选，跳过a。
3. b是当前输入紧随a的一帧；r是合法池按真实PTS紧随a的候选。r须未选、原有理采样目标为a后0.5秒、源时间严格位于a与b之间。缺映射、源重复或越界时不修复。
4. b不能是区域锚点或已保留Top-K种子。粗细来源不给b额外保护。
5. 使用冻结归一化BLIP视觉特征，s(x,y)=clip(fx·fy,0,1)。只接受Δ=s(a,r)−s(a,b)>1e−6的提议；该容差用于数值比较，不是语义判断阈值。
6. 按a的原问题ITM降序、Δ降序、a/r真实PTS和编号升序，选第一项。每题最多替换b一个槽位，其他位置和预算不变，不迭代。跨区实际配额变化另记，不能称重新优化了父版DP。

r来自已有2 FPS网格，不重评分、补查或提取特征。不要求邻接帧具有明显差异；相对视觉连续性也不保证同一事件或答案充分性。旧exp11改变整体目标与贪心求解、旧固定配对减半代表位置，本轮保持父输入主体。

## 离线范围与放行门槛

全量处理Video-MME2700×2与MLVU2174×2，记录全部提议、拒绝原因、实际选择、保护集合、粗细变化、跨区配额及Qwen两帧配对。原资产指纹、源映射及选择预算异常时暂停。

有界复核固定MLVU Q8、Video-MME113-3、386-1，以及103-1、383-2、395-2、306-2、170-2、544-1、844-1，共10题；最多追加两道按冻结题序出现的75项已列事实见证损失疑点。人工初审累计最多45分钟，不将未命中旧PTS直接认定语义证据损失。

进入小测须同时满足：全部输入与保护、预算验收通过；至少两个独立诊断错例的自动实际输入与已验证T相同；保护案例和已列事实警报无确认的必要事实损失及未解决关键疑点；选择及调用／引用分区事前冻结。

未通过则结束该固定规则，保留实现、反例和停止理由，不调整排序、保护范围或替换数量。诊断案例已参与设计，放行不视为独立泛化证据。

## 统计、判断与交付

主比较exp33−exp12，逐格报告exp07、Top-K、均匀参照、全部配对得失、触发子集、任务与时长；Video-MME按时长分层视频簇bootstrap，MLVU按内容视频簇重算七类M-Avg，10000次、种子2027。小测均已被历史评测，不称盲测。

四单元均不低于exp12，两个数据集各至少一个单元净增3题，且存在设计案例外跨视频改善依据，才建议讨论同版本全量。配置退化、仍弱于exp07、只有已知案例改善或必要事实损失均如实记录；不自动全量或再调参。

代码集中于独立选择模块、只读审计与批量入口，中文接口及步骤注释；不修改冻结选择器。产物保存于`outputs/methods/rd12_exp33_adjacent_context_20261015_r2/`，r1首次离线及原快照保留。包含9748项选择、固定复核、门槛判断、条件小测及调用／引用、指纹和恢复审计；未通过门槛的阶段明确记为未执行。研究计划、进展、索引增量更新，阶段review后独立提交，不推送。
