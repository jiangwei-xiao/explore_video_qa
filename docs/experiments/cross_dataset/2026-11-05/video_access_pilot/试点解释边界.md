# 受控原片访问试点的解释边界

## 研究假设与当前方法的结构限制

共享预览不意味着现有RD天然更省。设本题实际最终帧集合为S、大小k，RD为选择而获取的所有细帧集合为F。每题每方法原图缓存独立时，需要获取的唯一原图为F∪S：

`|F∪S| = k + |F| − |F∩S| ≥ k`。

仅取最终原图的Top-K/WFS通常只需k张；仅预览对照不获取原图。因此本轮可能支持的是“额外访问换来答题收益”或“区域访问改善特定解码成本”，不能预先主张RD减少原图数量。PNG字节不同还受画面压缩性影响，若出现字节优势，须同时看原图数量、解码量和画面内容，不能直接归因为证据更有效率。

当前检索仍对全片1 FPS预览执行问题相关BLIP评分，在线复杂度没有因模拟远端访问而消失。本轮也没有加入主动停止、按剩余成本调整补查范围的策略；8/32 MiB仅检查完整固定访问计划能否执行，超预算的完整回答不能计作预算内成功。

## 计时与标签边界

预览建设及共享索引是独立资产阶段。共同粗评分在本轮只实际计算一次以固定比较数值，每种检索策略按完整费用独立记账；原片缓存按题目/方法隔离。网络档用真实响应体重放，只测传输，不再次解码。分项合成时延与独立运行的远端E2E不是同一指标。

最终QA的媒体与提示由公开输入冻结。框架输入对象使用占位计分字母以避免向模型路径传递实际标签；调用内部的占位metric不作为成绩。真实标签在生成完整返回后用于正确数和官方任务计分复算，独立产物为`official_postgeneration_scoring.json`。原始Token、文字及提示不改写。

本轮若没有优势，只否定当前固定预览协议与原RD在该服务模型下的投入依据；不证明所有成本约束视频获取问题无意义。反过来，小面板出现优势也不代表已经解决真实边缘部署、跨地域网络、能耗或大规模泛化问题。
