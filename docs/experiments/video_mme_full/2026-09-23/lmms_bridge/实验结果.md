## 二、900视频均匀源帧对照

原规则：1 FPS、0.25秒相位候选池内均匀取帧。新规则：原源帧编号上`linspace(..., dtype=int)`，最多16个唯一帧。900视频/2700题全部覆盖；完整PyAV解码的PTS索引与旧源帧号对应通过，Decord独立帧总数及新索引核对900/900通过。

| 指标 | 结果 |
|---|---:|
| 新旧16帧序列完全相同的视频 | 0/900 |
| 平均精确源帧重合 | 0.524张/视频 |
| 重合0／1／2／3／4张的视频数 | 503／328／65／2／2 |
| 同位置时间绝对偏移均值／中位数 | 0.333秒／0.280秒 |
| 时间偏移P90／P95／最大值 | 0.667／0.800／1.339秒 |
| 新首帧平均提前／新末帧平均推后 | 0.267秒／0.495秒 |

同位置偏移基于898个两边均为16帧的视频，共14368个对应位置；两个帧数不同的短视频不混入该统计。首尾偏移使用全部900视频。

短视频133-1/2/3原14帧、134-1/2/3原11帧，新规则均能从原视频选16个不同源帧。不是重复帧补位，而是采样域从粗候选池变为原源帧。

**精确源帧重合少不等于画面语义差异很大。** 多数同位置偏移不足1秒，但可能影响瞬时线索；本轮没有使用新均匀帧回答，不能据此判断准确率升降。9个视频存在不同PTS步长，可能包含时基取整等情况，不直接都标为语义变帧率。

因此，后续新协议均匀基线不能直接复用旧1572/2700成绩。
