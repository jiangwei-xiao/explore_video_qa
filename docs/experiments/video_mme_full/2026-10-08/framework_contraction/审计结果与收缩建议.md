本轮完成exp07的K8、K16、K32全量等价重放：8100项最终源帧、局部前缀和区域配额全部一致，覆盖曲线最大误差0。新入口只接收帧预算K；历史M字段作为冻结接口兼容信息保留。已有问答精度由相同输入继承，本轮没有新精度成绩。

内部审计没有发现2秒连接、±4秒范围、3种子触发可以直接互相替代。可以统一派生统计、移出历史对照辅助量；优先行为收缩候选是将补查限制在真正触发的核心窗口并集，避免密集核心把补查传递到整个合并区域。该候选只形成设计，尚未改变正式选择或运行问答。

## 规则职责与冗余分类

| 规则或结构 | 实际职责及依据 | 收缩判断 |
|---|---|---|
| 独立M | 与K相等的运行没有额外自由度；适配重放一致 | 已取消新公开参数 |
| 核心连接2秒 | 决定种子间连接关系，并提供密度与连续触发统计 | 有独立作用；2秒最优性未得到证明 |
| 至少3种子触发 | 要求一个核心存在连续支持，区别于多处二种子聚集 | 不能由总密度直接替代 |
| ±4秒扩窗 | 定义取证范围，同时影响区域合并与后续组织 | 有独立作用；合并与补查范围存在耦合 |
| 2 FPS及网格相位 | 提供粗网格之外的时间观测，保持1 FPS为其子集 | 采样能力与一致性约束保留 |
| m、c、w | `w=1+m−c=1+连接总数` | 可以统一派生，不能把减少字段当作删除机制 |
| 完整原核心对象 | 生成阶段用于统计和窗口；下游选择/解码消费区域摘要 | 可把生产摘要和完整审计记录区分，无须删除连接规则 |
| 核心扩窗再合并 | 在一定源时间条件下可由种子窗口并集得到相同边界 | 数据上等价，但不具备无条件通用等价性 |
| 合并区域继承补查 | 一个核心触发，整个最终区域都密采样 | 优先检查的范围传播设计 |
| 最近窗口选择单元 | 为全部粗帧建立唯一归属、参考集合和预算竞争单位 | 作用独立；与补查窗口共用组织有耦合，尚无直接删减依据 |
| 每区锚点及正配额 | 强制保留定位入口，占用至少一个名额 | 设计约束，不是冗余统计 |
| 种子支持L与重复度D | 前者参照固定种子，后者参照动态已选集合 | 参照和职责不同，不能合成同一个量 |
| 粗帧覆盖与局部支持 | 前者评价预算前缀，后者生成局部次序 | 不能因都用视觉相似度而认定重复 |
| 可行参照配额 | 冻结函数的历史下界验收，不参与实际DP决策 | 新入口已隐藏；未来干净实现可移到验证层 |
| PTS映射及源帧去重 | 保证真实源身份和唯一输入，尤其覆盖VFR边界 | 必要输入约束，保留 |

当前`build_regions`集中计算核心摘要，并非维护多套独立密度参数。选择和补查函数不直接读取完整`plan['cores']`，因此可以减少生产层传递完整核心对象的依赖；完整核心记录仍是解释触发与审计的依据。当前冻结输出保持原样。

## 两个等价关系与一个反例

每个n种子核心有n−1条相邻连接，故`m−c`严格等于连接总数。补查触发则要求至少一个核心含3种子，即有两条连续连接。`[3,1]`和`[2,2]`的权重都为3，前者触发、后者不触发。用`w≥3`替代原触发会改变K8/K16/K32中的120/157/292个区域，不能称为等价整理。

若一个核心内任意相邻种子的真实源时间差都不超过两倍扩窗半径，其逐种子窗口并集等于“首末种子形成区间再扩窗”；再对全部核心合并也等价。本轮8100计划均满足该条件，最大核心内源间隔为2.039968秒，小于8秒，直接窗口并集全部一致。

但VFR反例成立：相邻粗目标0.25和1.25秒分别命中源帧0.25和9.25秒，原规则按目标时间把二者连成核心，扩窗得到连续的0–13.25秒；直接种子窗口并集为0–4.25和5.25–13.25秒。已有数据一致不能据此删除通用核心构建。相关反例已进入边界测试。

另外，在合并分组固定且相关边界没有被裁剪时，相邻选择单元的切点为`((末种子+4)+(首种子−4))/2`，半径抵消。±4秒对全局组织的主要连带作用来自区域合并/拆分，并非必然连续改变每个单元切点。

## 唯一优先行为收缩候选

候选为“只在真正触发的原核心窗口并集中补查”。规则明确如下：

1. 保留原Top-K种子、2秒核心连接与3种子条件。
2. 对每个达到条件的原核心沿用已计算的±4秒窗口，合并这些窗口，仅为解码去重形成补查范围。
3. 每个补查范围独立使用原对齐2 FPS网格，目标与映射后的真实源PTS均须在该范围内；越界与重复沿用现有记录规则。
4. 最终选择单元、种子支持集合、密度、锚点、全局粗资格及exp07等权覆盖DP保持原定义。

该改动删除“一个核心触发后整个合并区域继承补查”的隐含传播，不新增阈值，也不删除补查能力。它不是等价变换：细池、局部前缀、覆盖曲线和配额都可能改变，当前179/1865个外扩细帧入选位置不能预先判为无损。

后续先在同一冻结池中按精确目标与PTS筛出候选，做双配置离线重放，核查开头/关系见证、跨区域替代及外扩状态损失；通过后再review最多400次开发问答的具体方案。精度验收只接受持平或提高，代理值改善不等于答题改善。本轮未执行该删减选择或新问答。
