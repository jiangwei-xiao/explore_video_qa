# RD单预算接口与内部设计审计

本轮以RD-1.2-exp07为主要参照，将定位种子数量由唯一帧预算K派生，并检查条件补查和区域组织内部的冗余与耦合。验收要求维持现有选择；可能改变行为的删减只形成下一阶段方案。

## 固定范围

- 新公开接口仅接收`frame_budget=K`，种子数为`min(K,粗候选数)`；内部向冻结函数传递同一个K作为兼容种子上限。
- 复用全2700题的K8、K16、K32三份合法粗细池及特征，共8100项重放；K16的两模型共享选择只计算一次，同时核验各自源帧/RGB绑定。
- 种子、核心、窗口、配额、局部前缀、源帧与顺序必须一致，覆盖曲线绝对误差不超过`1e-6`。
- 新增BLIP、视觉编码、文本生成和最终问答均为0；历史M≠K记录、原算法、配置和结果保持原样。

## 内部设计核查

将固定选择（2秒连接、±4秒扩窗、3种子触发、2 FPS）、派生量（种子/核心/连接数、密度权重）和中间结构（核心、窗口、合并区域、选择单元）分别审查。分类为独立作用、可等价整理、可能过度设计或证据不足。

独立核对`m−c`与连接总数的关系，检验总密度是否能替代连续核心触发；计算整合并区域补查相对触发核心窗口并集扩大的目标范围及实际入选位置。后者仅是结构影响，不能据位置统计判定帧无价值。

直接从种子窗口并集构建区域的等价性，须同时给出数学条件、全量对照及VFR反例。粗帧归属与解码窗口的混用、区域合并对支持/去重/锚点/配额的连带影响均需明确。

## 执行与恢复

远端入口：`scripts/audit_framework_contraction.py`；环境：`/App/conda/envs/explore_video_qa/bin/python`。CPU最多8个任务，每任务BLAS线程1。长任务通过`nohup＋setsid`独立执行，stdin关闭，逐项原子保存、协议指纹和排他锁；完成态恢复只核验来源与产物，不再次选择。

```bash
/App/conda/envs/explore_video_qa/bin/python scripts/audit_framework_contraction.py \
  --run-id rd12_exp07_contraction_20261008_r1 --workers 8
```

来源绑定到历史池/特征检查点、选帧和前缀轨迹。异常暂停，不补算评分、细帧或特征。原始产物保存在`outputs/analysis/rd12_exp07_contraction_20261008_r1/`。

## 交付与验收

交付K接口、8100项等价记录、两个主要工作点的内部结构统计、最多6题既有画面复核和一个优先行为收缩方案。固定案例为103-1、383-2、395-2、409-3、035-2、844-1，复核不超过30分钟。

完成相关适配/选择回归及零模型调用恢复验收；研究计划、进展和索引增量归档。review通过后分阶段提交，不推送。帧预算配置和方法ID分别记录；本轮接口等价收缩不分配新算法版本。
