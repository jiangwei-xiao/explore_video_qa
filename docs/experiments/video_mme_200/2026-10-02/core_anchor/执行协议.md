# exp15：保留原检索核心的定位代表

核心问题：扩窗合并后只保护最终区域的一个峰值，是否让其他已经定位的入口被内部竞争覆盖？在exp12的200题中，2352个原核心峰值有545个未保留，涉及175题；102个最终区域的配额少于原核心数。这只是结构缺口，不等于545个有效证据损失。

## 固定规则与推导

基于exp12，不合入exp13/exp14。所有原问题Top32种子、2秒核心连接、±4秒窗口、原补查池、原特征和最终预算32保持不变。

1. 每个原几何核心取原问题ITM最高的一个种子，同分按PTS、编号升序。核心仍是时间连接结果，不解释为语义事件。
2. 一个最终区域可能合并多个核心，先固定这些核心峰值；按原ITM降序、PTS和编号排序，原区域最高峰仍为第一个。
3. 其余帧继续按原相关性加权种子支持×sqrt(差异度)构造局部前缀，重复度从全部固定锚点开始计算。不能把新锚点直接插进旧序列却不更新去重参照。
4. 沿用exp12原问题加权粗参考覆盖、原密度和精确DP，只将区域最低名额从1改为该区核心峰值数h_r。变量平移n_r=h_r−1+x_r后复用原DP，x_r≥1；目标仍为Σw_r C_r(n_r)，不另加核心奖励或配额系数。

原核心互不重叠且各至少含一个种子，故峰值总数不超过32个种子，不增加帧预算。单核心区域的局部规则精确退回exp12；若32个种子全为独立核心且预算32，直接保留原Top32。剩余名额仍自适应分配，不均分窗口。风险是强制保留重复、错误或低信息峰值，挤压有用的邻域证据。
