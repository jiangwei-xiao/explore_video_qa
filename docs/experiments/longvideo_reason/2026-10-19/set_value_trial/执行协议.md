# 独立长视频集合价值监督试点

状态：2026-10-19实施与资产阶段，尚无先导或学习成绩。运行编号`set_value_longvideo__llava8__train800_val400__20261019_r1`。本轮不是新RD方法版本；原NExT-QA验证200题封存，Video-MME/MLVU不新增问答。[主线工作台](../../../../research/RD主线收束与下一阶段推进.md)。

## 1．目标、输入与预算

只改变监督场景：更贴近长视频、具有真实候选取舍的监督，能否使原冻结BLIP表示和107073参数集合评分头获得独立视频净收益？

| 阶段 | 视频/题数 | 输入 | 真实教师问答上限 |
|---|---:|---|---:|
| 训练先导，包含在训练800内 | 200 | Uniform、Top-K、exp07、exp12、灰图G、异视频W | 1200 |
| 其余训练 | 600 | 四个真实同视频候选 | 2400 |
| 独立验证 | 400 | 四个真实同视频候选 | 1600 |
| 合计 | 1200 | 同题完整实际输入一致可共享 | 5200 |

合成教师另计，先导和主教师各最多4进程/每进程一次，总计≤8次。BLIP粗评分、补查纯视觉和集合表示额外ITM分别记账。CPU测试/Tokenizer/预处理不算模型前向或合成问答。共享划分和每阶段实际额度在首个生成前冻结，不按正确性择优复用。

## 2．固定源、资格与划分

- 标注为`LongVideo-Reason/longvideo-reason`，revision `311eccbd25e9646db8492fb6e728068828ee0684`。只用官方train Parquet 51200行；validation/test只用于隔离源身份，不使用转义异常的原始JSONL。
- 作者链接镜像`Perflow-Shuai/movie_mp4`，revision `3a290aa4592a8a10351f2be86293fdcf735970b5`。只取`n、h、Z、d、q、L、0、X`八包，189521777735字节；不扩全镜像。文件大小/官方LFS SHA在`longvideo_assets.py`逐项固定，标注同样核验。
- 完整视频实际时长180–1800秒，原题及四个不同选项可无歧义解析。保留原显示字母和顺序，包括D/A/B/C乱序。只归一化明确换行转义，禁止`unicode_escape`重写全文。
- 公开投影不含答案；`reasoning`不导出。参考字母另存计分文件，原始生成返回后才访问计分。B始终指原B项，不按列表位置重新映射。
- 排除官方validation/test、既有NExT-QA及目标评测的已识别同源/重复：使用源ID、完整SHA、既有8帧DCT指纹，沿用汉明≤6且顺序LCS≥6/8规则；新候选以并查集建立传递内容组。源身份不明或指纹缺失不能当作已查重。
- 有限8帧指纹不能排除全部局部复用；尚未下载的官方held-out素材只能核查其源ID及已有可对应身份，不能声称做过其全量字节/画面查重。教师预训练重叠未知。
- 容器时长先筛，完整流解码再验收真实PTS/int64源索引，不按平均FPS推算；不裁片、不重编码来修复资格。

合格内容组代表按`2027/set_value_longvideo_v1/video/源ID`的SHA256排序：前800训练、后400验证。视频内按`2027/set_value_longvideo_v1/question/原problem_id`选一道合格题，训练前200为先导。资格、分组、清单在教师前冻结；固定八包不足1200独立合格组就停止，报告缺口，不改时长/加包/借测试集。

实施已核实：官方test含数字ID/webm/mkv，须与train的11字符YouTube/mp4规则分开解析。51200行中50145满足四不同选项资格，1055行记录排除原因，仍覆盖17215个视频；这些不是时长和内容查重后的最终分母。

## 3．候选、表示与真实问答

四候选为BASE-Uniform、BASE-BLIP-TopK、RD-1.2-exp07、RD-1.2-exp12。复用冻结`selection.prepare_one`：Uniform原源帧编号均匀；其他1 FPS/.25秒、原问题BLIP、2秒核心/±4秒扩窗/原合并、3种子条件2 FPS补查，单预算K=8。每组8唯一源帧，非截取旧16/32帧结果。

BLIP-1仍FP32/官方384/batch16/禁TF32/不截断。小头表示为每帧问题融合CLS768、ITM、相对源时间，共770维。为最终帧补算的融合前向仅服务小头，不回写选择；选择使用原分数和纯视觉。

教师沿用`explore_video_qa_lmms`：LLaVA-Video-7B-Qwen2、BF16/SDPA、384官方预处理、`qwen_1_5`，8帧1680视觉Token；贪心/batch1/seed2027/max_new_tokens16。原题与原序四选项后附`Answer with the option's letter from the given choices directly.`。不加入音频、外部字幕、reasoning、时长或PTS文字。

本轮独立四选项任务桥真正执行固定LMMs-Eval `LlavaVid.generate_until`，不冒用NExT-QA或Video-MME文字。严格接受完整A–D、A.或(A)，解释文字/失败不猜答案、不重跑。

G为8张RGB128灰图；W仅用训练800内不同内容、时长最近供体的native均匀8帧，同差固定哈希。供体不依赖BLIP/模型对错，不使用验证视频；G/W不入训练。

## 4．先导门槛与唯一训练/验证

1. 固定资产全SHA、完整PTS及内容资格通过后冻结1200清单；来源不足则结束资产阶段。
2. 仅准备先导200四候选及G/W，冻结完整提示Token/官方像素/RGB/源顺序和共享预算，工程正确性放行，不按准确率调配置。
3. 200先导须≥40有效偏好视频，任一候选正确数比最好固定方法至少多10题；Uniform−G和Uniform−W的配对95%区间下限均>0。
4. 固定先导序前6题＋最早6道未重复混合反馈题，最多12题/60分钟；≥10题受静音画面合理支持，且≥3偏好视频确认候选信息取舍。未确认不计通过，不改题/加特殊保护。
5. 定量失败就停止。定量通过但实际画面审核尚未完成，后台进入`waiting_for_bounded_pilot_review`，不冒充已审核；面板SHA绑定的实际审核通过后自主接续，不再询问实验范围。
6. 释放先导教师，准备剩余600训练及400验证候选/特征；补齐600训练四候选反馈，复用先导真实候选答案。
7. 一次CPU训练：原头/原排序损失，FP32、AdamW lr.001/wd.0001/batch32/seed2027，从原初始化≤2000更新；每20步检查训练有效题平均偏好和所选组答对率，均≥95%连续3次停止。未拟合不生成验证答案。
8. 先冻结400验证题的新头选择、训练800选出的最好固定方法、平均ITM、旧NExT-QA充分拟合180步头选择；旧头SHA `8f069aa8288dbe012d1e7e9b69e2e18e46126ab904dfd6d8c02f54d5f398655f`。预测接口不读取验证反馈，发布后才允许验证问答。
9. 完成一次400验证和报告；无第二个网络/学习率/种子，不自动转Qwen或目标基准。
