## 3．目前能得出什么

1. 更长场景提供了更多**标签层**取舍：本先导41/200有偏好，旧NExT-QA训练为47/600；两者都提供111个去重比较。数据源和问题不同，不能归因为纯时长效应，也不等于这些偏好都具有可靠视觉依据。
2. Uniform对G/W的优势支持本面板存在平均视觉贡献，不能说教师完全不看视频。另一方面G/W仍答对118/115题，正确性标签并非天然等于画面信息价值；这也不证明题库记忆或逐题无视觉依赖。
3. Mac Pro、手机、蛇、珊瑚案例保留真实信息取舍线索；NASA等案例又说明线索仍在而回答变化，不能统一解释为选帧失败。
4. 当前“固定来源＋四候选＋冻结表示＋教师正确性反馈”未满足事前语义质量门。按协议停止，而不是补题、改门槛、加训练步数或训练第二个结构。

**下一步优先复核这些具体争议、明确视觉监督的可核查标准和来源适配；不直接扩大教师标注或扫描小头超参。** 后续若更换来源、资格规则或审核标准，应另行review并冻结协议，不能在本轮按对错替换题目凑过门。当前RD-1.2/exp07/exp12仍冻结，没有新方法版本或新全量收益。
