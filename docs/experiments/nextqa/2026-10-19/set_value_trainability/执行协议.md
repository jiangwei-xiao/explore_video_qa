# 集合价值学习：训练充分性与监督适配诊断

日期：2026-10-19（北京时间）。运行`set_value_trainability__nextqa600__20261019_r1`。主线入口为[持续工作文档](../../../../research/RD主线收束与下一阶段推进.md)。

## 固定问题与资产

原800题试点的600训练题只有47题提供111个唯一正负比较，原20epoch实际40步。先核查训练充分性，再检查视频级泛化。原200题的答案、特征及预测不用于本轮新头的训练或评价；仅以文件哈希证明历史不变。

本轮复用原特征和答案，新增BLIP、视觉骨干、辅助生成、最终QA均0。只运行CPU小头、2线程；既有RD算法、模型环境和正式成绩保留。小头训练更新与CPU时间单独记账。

## 执行顺序

1. 冻结训练600题输入绑定、五折清单、协议、来源与代码哈希。五折仅按视频ID的`stable_key('set_value_diagnostic_cv', video_id)`排序轮流分配，每折60视频/120题；留出有效偏好数6/13/10/8/10。
2. 描述NExT-QA训练600题及Video-MME/MLVU在LLaVA8、Qwen32的9748个历史题目配置：全对/全错/正负混合、完整输入去重、源帧Jaccard、唯一正负比较、四银行任一答对与最好固定方法差距。按官方任务/时长及固定0–180、180–600、600–1800、>1800秒分箱，逐项披露分母。MLVU使用既有完整选项句点归一化结果。
3. 检查训练特征/答案对应、正负特征碰撞、梯度、权重更新与分数间隔；若同完整输入正确性冲突，训练暂停，目标描述统计单列冲突，不制造偏好。不同源帧/答案不解释为语义证据不同。
4. 复用原107073参数头、770维输入、题均排序损失、FP32、AdamW lr0.001/weight_decay0.0001、batch32、种子2027。从原初始化重放40步，模型和优化器绝对误差≤1e-6、600题训练选择一致后，沿同一轨迹继续。
5. 最多总计2000步，每20步只在有效训练题上检查偏好正确率和最高分组答对率；两者均≥95%连续三次时停止。每步原子保存参数/优化器/游标；完成恢复不更新，部分恢复从最近已提交状态继续。2000步仍未通过时结束训练分支，不运行CV。
6. 通过后五折各自独立初始化，训练器仅接收其480题及标签，不继承全600题检查点。相同2000步上限和训练停止规则，留出预测发布后才由汇总器匹配旧标签。最多六条轨迹、12000步。

## 比较与解释

合并600题折外预测，对照每折训练部分选出的最佳固定方法、四固定方法和平均ITM。报告题均偏好、全600正确数、所有配对得失、选择分布、每折训练能力及视频簇bootstrap10000次/种子2027。回顾性CV不是新独立基准成绩。

若充分拟合且折外偏好≥60%、相对训练折最佳策略净增、改善来自≥3视频、并不低于四固定方法中最好结果，支持讨论独立监督扩展；不自动新增问答。若训练未充分拟合，或仅训练改善而折外无益，按证据分别记录训练能力或泛化不足，不扫描新结构/学习率/种子。
