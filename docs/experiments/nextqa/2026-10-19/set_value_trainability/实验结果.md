# 集合价值学习：训练充分性与监督适配诊断结果

日期：2026-10-19（北京时间）。状态：完成，停止本轮固定诊断；不自动扩监督、改结构或新增问答。

## 1．核心结论

**原40次更新确实不足，但充分拟合后仍未取得跨视频收益。** 同一评分头沿原轨迹到180步即可通过训练门槛；五折各自也能拟合训练部分。600题折外结果为523正确，与“各折仅由训练部分选出的固定策略”持平，低于全600题上最好的固定exp07（527正确）。折外偏好正确率44.50%，未达到60%的后续投入条件。

因此本轮排除了“评分头完全不能学会当前训练偏好”的解释，但没有建立可迁移的集合价值学习能力。监督稀疏与目标场景差异是真实现象，尚不能据此证明扩大数据就能解决问题。

## 5．决策与下一步边界

1. **训练能力成立**：原头能充分拟合现有偏好；不再把原40步表现当作该表示完全不可学的证据。
2. **跨视频泛化尚未成立**：充分训练后没有超过主参照，也未达到折外偏好60%及不低于最好固定策略的投入条件。当前不能通过继续增加更新数宣布突破。
3. **监督适配值得下一轮讨论，但尚未放行扩展**：应先明确独立训练任务是否能提供与长视频、紧预算相关的稳定差异，以及当前表示能否区分这些差异；不能自动增加教师调用、换数据重测或恢复窗口微调。

停止本轮固定诊断，保留RD-1.2、exp07、exp12及旧试点。没有新方法编号，没有Video-MME/MLVU新增答案；本轮不宣布学习路线整体无效，也不承诺换数据必然改善。
