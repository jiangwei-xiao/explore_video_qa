## 3．表示、小头及监督

每帧向量`x=[normalize(问题融合CLS), ITM, 相对真实时间]`，维度768+1+1。选择器仍使用原ITM/纯视觉特征；从同次前向旁路记录融合CLS，不反馈改变四组选择。最终入选均匀/细帧若缺少融合表示，仅补算其原问题ITM/融合表示，成本另记，不追溯改选帧。

小头为共享`770→128→64`、GELU，逐帧均值和最大值汇聚后`128→1`，共107073参数。集合表示不接收选项、答案、方法ID或教师预测；只有相对源时间作为数值位置输入，不将源ID当特征。

同题正组为教师答对、负组为教师答错，使用`softplus(g(负)-g(正))`；先同题所有正负对平均再按题平均。相同输入不重复投票，全对/全错题保留统计但不生成伪偏好。FP32、AdamW lr0.001/weight_decay0.0001、种子2027、每批32道有效偏好题、固定20epoch，使用最后一轮，不早停/不按验证择模。若无偏好信号，报告并停止，不追加监督。
