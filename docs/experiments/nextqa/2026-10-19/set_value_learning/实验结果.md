日期：2026-10-19（北京时间）。正式批次`set_value_learning__nextqa800__llava8__20261019_r2`；r1仅为保留的失败准备批次，正式QA为0。见[执行协议](执行协议.md)和[主线工作文档](../../../../research/RD主线收束与下一阶段推进.md)。

## 1．结论

**本固定实现未通过继续投入门槛，结束本轮，不扩大到Video-MME／MLVU，不登记exp35、不升级RD默认方法。**

冻结LLaVA-Video-7B-Qwen2／K8，在独立视频划分的200题验证上，学习选择160/200（80.00%）：比训练集选出的最佳固定方法exp07多2题，但比验证集均匀少2题；偏好正确率42.11%，只有19题具有可比较的正负组。不能称为稳定的回答价值学习或统一exp07／exp12的成功。

这不是学习路线的普遍否证。当前四候选的有效监督稀疏，训练集自身也未建立强排序：600题仅47题产生偏好、训练偏好正确率58.51%，损失0.69317→0.68500。现有证据不能区分数据量、表示/集合头能力和固定训练设置的贡献，**不能简单归为过拟合，也不能据此证明选帧精度上限。**

## 3．本轮最有指导意义的现象

- **监督密度低。** 训练501题四组都对、52题都错，只有47/600（7.83%）、46个视频提供排序监督；同输入去重后共111个正负比较。全对/全错没有被强行改为偏好标签。批量32、20epoch实际只有40个优化更新。
- **验证也很少出现差异。** 149题四组都对、32题都错、19/200（9.50%）有正负差异。四固定组任一答对为168题，比最好固定方法多6题；这只是有限银行的事后可达题数，绝不是全部选帧算法的上限。
- **未学到均衡的组合。** 验证选择Top-K181题、均匀9题、exp07为10题、exp12为0题。相对直接Top-K只净增1题，不能据此宣称已经结合两版优势。
- **训练拟合本身有限。** 偏好正确率训练58.51%、验证42.11%，分母分别47、19；损失仍接近初始值。既不能把训练总体87.67%当作排序学会了，也不能只看训练/验证总体准确率差宣布过拟合。
- **格式和数据泄漏不是本次已见解释。** 两阶段真实生成解析失败均0；验证选择事前冻结；源帧、真实输入及小头重放验收通过。没有将教师答对自动解释为证据充分。

后续若再讨论学习路线，应先确认能否获得更充足且可辨识的组间差异，以及固定表示/集合头能否在训练偏好上建立明确能力，再决定独立验证；本轮不实施数据扩容、增加epoch、改损失或换表示。继续手调RD窗口/余弦并非由本结果推出的下一步。
